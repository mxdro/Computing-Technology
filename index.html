Welcome to Computing & Technology

Computing and technology play an important role in our daily lives. They help people communicate, learn, work, store information, and solve different problems.

This website presents important topics about computers, information systems, databases, networks, hardware, software, and Microsoft Excel.

1. History & Forms of Computing

Computing is the process of using computers and other devices to process information and solve problems. Computers have developed over time, from simple calculating tools to modern powerful machines.

History of Computing

  • Abacus: An early counting tool used for calculations.
  • Mechanical Calculator: A machine designed to perform mathematical operations.
  • First Generation: Computers used vacuum tubes.
  • Second Generation: Computers used transistors.
  • Third Generation: Computers used integrated circuits.
  • Fourth Generation: Computers used microprocessors.
  • Modern Generation: Computers use advanced technologies such as artificial intelligence.

Examples of Computing Devices

Device Purpose Example
Desktop Computer Used for office work, school, and entertainment. Personal computer
Laptop A portable computer for studying and working. Notebook computer
Smartphone Used for communication, applications, and internet access. Android phone
Server Provides services and information to other computers. Web server
Remember: Computing technology continues to improve and makes many daily activities easier and faster.

2. Information Systems

An Information System (IS) is a combination of people, technology, processes, and data that work together to collect, process, store, and distribute information.

Components of an Information System

  1. Hardware: Physical parts of a computer.
  2. Software: Programs and applications.
  3. Data: Raw facts that can be processed.
  4. People: Users who operate the system.
  5. Processes: Steps followed to complete tasks.

Types of Information Systems

Type Meaning Purpose
TPS Transaction Processing System Records daily transactions.
MIS Management Information System Provides reports for managers.
DSS Decision Support System Helps people make decisions.
OAS Office Automation System Helps with office activities.
Example: A school enrollment system stores student information, grades, and enrollment records.

3. Database & MySQL

A database is an organized collection of information that can be stored, accessed, managed, and updated. It helps users organize large amounts of data.

What is MySQL?

MySQL is a relational database management system used to store and manage information. It uses SQL (Structured Query Language) to work with data.

Important Database Terms

  • Table: Organizes data into rows and columns.
  • Row: A single record in a table.
  • Column: A category or field of information.
  • Primary Key: A field that uniquely identifies each record.
  • Foreign Key: A field that connects related tables.

Example of a Student Database Table

Student ID First Name Last Name Course
001 Juan Dela Cruz BSCS
002 Maria Santos BSIT
003 Pedro Reyes BSCS

Basic SQL Commands

SQL Command Purpose
CREATE Creates a database or table.
INSERT Adds new records.
SELECT Retrieves information.
UPDATE Changes existing records.
DELETE Removes records.
Example: A school can use MySQL to manage student records, enrollment information, and grades.

4. Computer Memory & Storage

Computer memory and storage are used to keep data and instructions. They help computers operate and save information.

Types of Computer Memory

  • RAM: Temporary memory used while the computer is running.
  • ROM: Memory that stores important instructions.
  • Cache: Small, fast memory that helps the CPU access data quickly.

Types of Storage Devices

Storage Description Use
HDD Hard Disk Drive Stores files and programs.
SSD Solid State Drive Fast storage for computers.
USB Flash Drive Portable storage device Transfers and saves files.
Memory Card Small removable storage Stores photos and other files.

RAM vs ROM

RAM ROM
Temporary memory Stores important instructions
Usually loses data when power is off Retains its contents without normal power
Used for running programs Used for firmware and startup instructions

5. Data Communication & Networks

Data communication is the exchange of information between two or more devices. A computer network connects devices so they can share information and resources.

Elements of Data Communication

  1. Sender: The device that sends the information.
  2. Receiver: The device that receives information.
  3. Message: The information being sent.
  4. Transmission Medium: The path used to send data.
  5. Protocol: Rules used for communication.

Types of Computer Networks

Network Meaning Coverage
PAN Personal Area Network Small personal area
LAN Local Area Network Home, school, or office
MAN Metropolitan Area Network City or large campus
WAN Wide Area Network Large geographical area

Transmission Media

  • Wired: Uses cables such as Ethernet and fiber optics.
  • Wireless: Uses signals such as Wi-Fi and Bluetooth.
Example: When you send a message through the internet, your device communicates with another device through a network.

6. Computer Hardware

Computer hardware refers to the physical parts of a computer that can be seen and touched. These components work together to perform different tasks.

Main Parts of a Computer

  • CPU: The Central Processing Unit processes instructions.
  • Motherboard: Connects the computer's main components.
  • RAM: Provides temporary working memory.
  • Power Supply: Provides electrical power to the computer.
  • Storage Drive: Saves files and programs.

Input and Output Devices

Input Devices Output Devices
Keyboard Monitor
Mouse Printer
Scanner Speaker
Microphone Projector
Webcam Headphones

Types of Monitors

  • CRT (Cathode Ray Tube): An old, bulky monitor that uses electron beams to display images.
  • LCD (Liquid Crystal Display): A thin monitor that uses liquid crystal to display images.
  • LED (Light Emitting-Diode): A monitor that uses LED lights to produce bright images.
  • OLED (Organic Light Emitting-Diode): A monitor that produces its own light for clearer images and better images.
Remember: Hardware needs software to perform useful tasks.

7. Software & Keyboard Shortcuts

Software refers to programs and instructions that tell a computer what to do. Unlike hardware, software cannot be physically touched.

Types of Software

Type Description Examples
System Software Manages computer hardware and basic operations. Windows, Linux
Application Software Helps users perform specific tasks. Word, Excel
Utility Software Maintains and protects the computer. Antivirus, Disk Cleanup
Programming Software Tools used to create computer programs. Compiler, Code Editor

Common Keyboard Shortcuts

8. Microsoft Excel

Microsoft Excel is a spreadsheet application used to organize, calculate, analyze, and present data. It uses rows, columns, and cells to arrange information.

Important Excel Terms

  • Workbook: An Excel file.
  • Worksheet: A sheet inside a workbook.
  • Cell: The box where a row and column meet.
  • Row: A horizontal line of cells.
  • Column: A vertical line of cells.
  • Formula: An expression used to calculate values.

Common Excel Formulas

Formula Purpose Example
SUM Adds numbers. =SUM(A1:A5)
AVERAGE Calculates the average. =AVERAGE(A1:A5)
MAX Finds the highest value. =MAX(A1:A5)
MIN Finds the lowest value. =MIN(A1:A5)
COUNT Counts cells containing numbers. =COUNT(A1:A5)
